# Rahul Birajadar — Developer Portfolio

One-page developer portfolio built with React 19, TanStack Start (file-based routing + server functions), JavaScript/JSX, CSS Modules and Lucide icons.

## Folder structure

```text
src/
  components/        Reusable UI pieces (JSX components + CSS Modules)
  sections/          One folder per portfolio section
  data/portfolio.js  All text, links, skills and projects
  hooks/             useScrollSpy (active nav link), useTheme (dark/light)
  lib/               Contact validation, server functions and shared utilities
  integrations/      Supabase client and server integration
  routes/__root.jsx  App shell: HTML, fonts and metadata
  routes/index.jsx   Home page: assembles the portfolio sections
  routeTree.gen.js   Generated by TanStack Router; do not edit manually
  styles.css         Design tokens and global styles
public/resume.pdf    Downloadable resume
```

## Environment setup

Copy `.env.example` to `.env` and fill in the Supabase values for your own project. Do not commit `.env` or share its values publicly.

## Run locally

Install dependencies with one package manager:

```bash
bun install
bun run dev
```

Or use npm:

```bash
npm install
npm run dev
```

Other scripts:

```bash
bun run test       # run tests
bun run lint       # lint JavaScript/JSX
bun run build      # production build
bun run preview    # preview the production build
```

## JavaScript routing

`tsr.config.json` sets TanStack Router's `disableTypes` option so the route tree is generated as JavaScript (`src/routeTree.gen.js`). Keep this setting enabled and do not hand-edit the generated route tree.

## Deploy

- **Lovable**: publish from the editor; the existing contact-form server functionality is retained.
- **GitHub**: connect the project to GitHub from the editor; changes can sync to your repository.
